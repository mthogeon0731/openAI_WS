## 비교 기준과 증거

- 원본: 사용자가 제공한 `Sogang Student Collective.html`의 **1a Glass Console**. 다운로드 원본은 작업 폴더 `design-references/sogang-glass/reference.html`에 보관했습니다.
- 구현: `src/page.mjs`, `src/styles.css`, `src/main.js`를 빌드한 `http://localhost:5179/`.
- 데스크톱 CSS viewport: 1440 × 1000, DPR 약 1, 한국어 홈, 기본 밝은 테마, 스크롤 맨 위.
- 원본 전체 캡처: 1429 × 1616px. 구현 전체 캡처: 1424 × 1640px. 원본 회전 SVG의 가로 넘침으로 생기는 오른쪽 여백을 제외하고, 두 이미지의 같은 원점에서 1424 × 1000px를 잘라 1:1로 비교했습니다. 늘이거나 축소하지 않았습니다.
- [나란히 놓은 전체 비교](docs/qa/comparison-desktop.jpg): 왼쪽 원본, 오른쪽 구현. 제목·문구·메뉴 수는 검증된 서강대 콘텐츠에 맞춰 의도적으로 변경했습니다.
- [제목의 글꼴·행간 비교](docs/qa/comparison-type.jpg): 같은 좌표의 700 × 215px 영역을 나란히 배치했습니다.

## 발견과 수정 이력

1. **P2 — 회전 워터마크가 가로 스크롤을 생성.** 초기 구현의 회전 SVG 경계가 viewport를 넘었습니다. `.watermark { contain: paint }`로 장식의 그리기 범위를 제한했습니다. 수정 후 데스크톱·모바일의 8개 경로 모두 가로 넘침 없음. 최종 비교 이미지에 반영했습니다.
2. **P2 — 학습 섬 이미지 높이가 서로 다름.** 첫·세 번째 카드의 그림 영역 340px, 두 번째 240px로 본문 시작선이 달랐습니다. 데스크톱 그림 영역을 240px로 고정하고 작은 화면에서 별도 높이를 적용했습니다. `learn-final.jpg`에서 그림·본문·버튼 정렬을 재확인했습니다.
3. **P2 — 운영 데이터 수정이 일부 화면에 전달되지 않음.** 행사 날짜·장소·주제를 `content.mjs`로 모으고 홈·상세·달력·로드맵·Recap을 같은 데이터에서 생성하도록 수정했습니다. UTC→KST 날짜 변경, 월 첫 요일, 2028년 2월 윤년 날짜도 별도 확인했습니다.
4. 영문 학습 화면의 요청문을 추가하고 언어 전환 후 복사할 본문도 영어로 바뀌는지 확인했습니다.

최종 나란히 비교와 별도 시각 검토에서 남은 P0/P1/P2 문제는 발견하지 못했습니다. 초 단위 카운트다운과 회전 링의 각도 차이는 촬영 시각 차이입니다.

## 동작 검증

- 자동 검사 10/10 통과: 8개 경로, 기본 표시 상태, 링크·자산·폰트·ICS, 데이터와 컨트롤 연결, 행사 시작/종료 경계, 음수가 없는 카운트다운, UTC 캘린더 변환·한글 줄 접기, HTML escape, 서버 MIME·경로 제한.
- `npm run build:sogang` 성공. 외부 런타임 패키지 설치 불필요.
- Chrome에서 8개 경로를 데스크톱/375px 모바일에서 직접 이동: 가로 넘침·깨진 이미지 없음.
- KO/EN 전환과 영문 요청문, 메뉴 선택 후 닫힘, Escape 닫힘·포커스 복귀, 없는 경로 안내·뒤로 가기 확인.
- 미션 체크 후 새로고침해 `1 / 3` 유지, 요청문 복사 성공 알림 확인.
- 관리자에서 GitHub API의 실제 커밋 `eb6e457`을 조회. 모의 로그인·성공 로그 없음.
- Google 지도 iframe을 화면 안으로 스크롤해 **서강대학교 정하상관** 표식 확인. 지도는 지연 로딩하므로 스크롤 전 전체 페이지 캡처에는 빈 영역으로 나올 수 있습니다. 세 지도 서비스 링크는 상시 제공됩니다.
- 브라우저 경고·오류 로그 없음.

## 의도된 범위

- 학습 체크는 브라우저 안에만 저장됩니다. 인증·출석 제출·서버 동기화는 제공하지 않습니다.
- 관리자는 실제 GitHub 편집 링크와 변경 이력 조회입니다. 목업의 가짜 OAuth·커밋·빌드 성공 애니메이션은 구현하지 않았습니다. 현재 Sites 미리보기의 자동 배포 연결은 별도 설정이 필요합니다.
- Studio와 Showcase는 일정 준비 중입니다. 공개할 실제 활동 사진·프로젝트가 없어 Recap에는 행사 안내와 자료만 제공합니다.
- 현재 확인은 Chrome에서 수행했습니다. Safari·Firefox의 별도 실기 검증은 하지 않았습니다.
